# AGENTS.md

macOS (Apple Silicon) dotfiles: zsh, Starship, Ghostty, git with SSH commit signing, mise, Homebrew.
This repo is **public**.

## Layout

- `home/` mirrors `$HOME`. Every file in it is symlinked into place by `install.sh`
  (e.g. `home/.config/ghostty/config` → `~/.config/ghostty/config`).
  Editing the symlinked file in `$HOME` edits the file here.
- `Brewfile` lists Homebrew formulae and casks.
- `install.sh` is the bootstrap: link files (backing up anything already there), install Homebrew,
  `brew bundle`, fix zsh completion permissions, `mise install`. It must stay safe to re-run.

## Rules

- **No personal data or secrets in the repo.** Git identity (name, email, signing key) lives in the
  untracked `~/.gitconfig.local`, loaded by `[include]` in `home/.gitconfig`. Never add `[user]` to
  `home/.gitconfig`. Use the GitHub noreply address, never a personal email.
- Use `~` or `$HOME`, not `/Users/<name>`, in config paths.
- Adding a config file: put it under `home/` at its `$HOME`-relative path, then run `./install.sh`
  (or replace the original with a symlink to it).
- Adding a Homebrew package: `brew install <pkg>`, then
  `brew bundle dump --file=~/dotfiles/Brewfile --force`.
- Adding a language/runtime: `mise use -g <tool>@<version>` (writes `home/.config/mise/config.toml`).
- In `home/.zshrc`, guard tools with `command -v <tool> >/dev/null &&` so the shell still starts when
  one is missing, and keep `zsh-syntax-highlighting` sourced last.
- `home/.config/starship.toml` is generated by `starship preset nerd-font-symbols`; customize on top of it.
- Commits are SSH-signed via the Proton Pass agent (`SSH_AUTH_SOCK` in `.zshrc`). If signing fails,
  Proton Pass is locked or not running; do not disable `commit.gpgsign`.

## Verifying a change

    zsh -il -c 'echo ok'            # shell starts without errors (ignore "can't change option: zle" without a TTY)
    time zsh -il -c exit            # startup should stay well under 0.2s
    ./install.sh                    # re-run is a no-op on an already set-up machine
    git log --show-signature -1     # signature is "Good"
